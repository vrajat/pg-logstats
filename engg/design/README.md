## Design Doc Expectations

Substantial design docs in this directory may take one of two shapes:

1. ADR-style design records for decisions that need explicit context, decision,
   consequences, and alternatives
2. broader design plans for implementation sequencing, rollout, or open-ended
   workflow exploration

When a document is making a durable product or interface decision, prefer the
ADR-style structure.
